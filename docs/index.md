## 🚀 Using the CLI

```bash
# Install
pip install -e .

# Search for alternatives
selfhosted search "notion"

# List all tools in a category
selfhosted list --category productivity

# Add a new tool
selfhosted add "Toggl" --alternative "ActivityWatch"
```
